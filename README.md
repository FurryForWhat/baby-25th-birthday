# Birthday Website — GitHub Pages

This is an original-photo birthday website with 22 photos, unchanged.

## Publish using GitHub website

1. Visit https://github.com/new while logged in.
2. Repository name: baby-25th-birthday
3. Select PUBLIC (GitHub Pages site is public). Create repository.
4. EXTRACT this ZIP on your computer. Do NOT upload the ZIP file itself.
5. On your new repository page, select Add file -> Upload files.
6. Drag index.html, the entire photos folder, .nojekyll and optionally music folder and README.md onto the upload page. Make sure index.html lands at repository root, not inside a parent folder. Commit changes to main.
7. In repository Settings -> Pages, choose Deploy from a branch, main and /(root); save.
8. Open https://YOUR_USERNAME.github.io/baby-25th-birthday/ after GitHub Pages finishes publishing.

Privacy: This publishes the photos online. The original-photo gallery should be posted only with the photo subject's consent. A password prompt implemented only in HTML or JavaScript does NOT make a public GitHub Pages site private.

Music: If you have rights to host the MP3, place it at music/zenith-come-here.mp3; click the music toggle on the site to start playback.
